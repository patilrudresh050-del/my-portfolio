# Rudragoud Patil — Developer Portfolio

A responsive React + TypeScript portfolio using Vite, Tailwind CSS, Framer Motion, Three.js / React Three Fiber, Drei and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```
